# CPUthermal 1.6.2-154+isolation.6

适配 iOS 15–17，提供稳定高性能与 CPU 专用低功耗模式。稳定高性能模式阻止用户态热缓解，保持原生 CPU 调度；低功耗模式仅下发 CPU 专用预算/频率策略，不启用全局省电模式，也不改变亮度。独立的显示亮度保护、智能充电限制、FaceDownLock、设置内电池页面修复和控制中心模块继续保留。

本版**彻底移除**旧版刷新率强制功能的设置、过滤器、Hook、动态 source、保活、UI/CALayer 模块和独立 dylib；也彻底移除面板内诊断开关、后台文件日志和相关调试路径。未新增 UI observer 或 Timer；保留现有温控、亮度与充电所需的通知及定时机制。升级后旧版的刷新率 dylib 由包管理器移除。

**边界**：只作用于用户态策略，不保证持续最高频率、帧率、亮度或充电行为；无法绕过固件/硬件紧急保护。切勿以危险升温验证。

选择对应越狱环境的一个 DEB：Rootless 或 RootHide。安装/升级脚本重启 thermalmonitord 并重新加载充电守护；安装后手动重启用户空间，使其他已运行进程重新载入插件。可运行 `python3 -m unittest discover -s tests -v` 验证静态和模拟合同，实际硬件行为仍需真机测试。
