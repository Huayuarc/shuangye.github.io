# 地震信息提醒 1.1.0：审查与改进说明

## 定位与限制

本项目是面向**越狱 iOS 15+** 的 Theos/ElleKit（或 MobileSubstrate）插件，由 launchd 守护进程轮询公开地震目录，再通过 Darwin Notification 通知 SpringBoard 显示全屏警报。

它目前属于“震后地震目录提醒”，**不等同于安卓厂商接入的官方地震预警（EEW）**：USGS、EMSC 等公开目录通常在地震发生后才发布，叠加 10–120 秒轮询周期，不能稳定提供 P 波到达后的倒计时。请勿把它作为唯一避险依据，也不应宣称可以替代政府、运营商或手机厂商的官方预警通道。

## 已修复的关键问题

1. 修复关闭第一次全屏警报后 `_alertShowing` 永远不复位，导致后续地震全部漏报。
2. 修复 `soundEnabled`、`vibrateEnabled` 设置完全未生效。
3. 没有自带 `alert.caf` 时改用系统警报音，不再把“振动 ID”误当警报声音。
4. 修复 `enabled` 只在界面层生效、守护进程仍持续处理与广播的问题。
5. 每轮重载震级阈值等偏好；轮询间隔在守护进程启动时按设置应用。
6. 增加事件时效过滤（默认仅接受最近 10 分钟事件）与未来时间异常过滤，降低旧震误报。
7. 首次安装或清空状态后建立目录基线，不会把目录内已有地震一次性当成新警报。
8. 事件处理由“按震级”改为“按时间”，避免多个事件同时出现时先报旧的大震。
9. 修复窗口查找兼容性，不再依赖不稳定的 `UIWindowScene.keyWindow` 用法。
10. 测试事件 ID 改为时间戳，测试按钮可重复使用。
11. 补充 `waitpid` 正确头文件。
12. 旧 CEIC `speedsearch` 地址实际返回“页面未找到”HTML，已替换为 HTTPS EMSC FDSN GeoJSON 备用源，并校验 HTTP 状态与 JSON Content-Type。
13. GeoJSON 解析器同时兼容 USGS（毫秒时间戳）和 EMSC（ISO 8601 时间、`flynn_region`、`unid`、负深度坐标）字段。
14. 设置页、状态页和软件包描述改为准确表述，明确“非官方秒级 EEW”。

## 与安卓系统级地震预警仍有差距

- **没有官方 EEW 实时流**：这是最关键差距，客户端 UI 无法弥补数据源能力。
- **没有用户位置与预计烈度**：仅按震级报警会造成大量远距离无感提醒。
- **没有 S 波到达倒计时**：必须有低延迟震源参数、设备位置和可信传播模型。
- **没有系统级关键警报权限**：越狱注入可做全屏提示，但稳定性、安全边界和勿扰模式行为不同于 Apple Critical Alerts / 政府警报。
- **本地通知身份不完整**：launchd 命令行工具不是正常注册的 App，不能可靠地自行申请通知授权；锁屏能力仍主要依赖 SpringBoard 注入。
- **缺少数据签名、权威源鉴别、端到端延迟监测、演练模式、故障遥测和大规模实机验证**。

## 推荐的下一阶段架构

1. 对接有正式授权和 SLA 的中国官方/厂商 EEW 推送接口；不要抓取网页冒充实时预警源。
2. 服务端统一接入多权威源，做事件合并、修订序号、撤销消息、签名与 APNs 推送。
3. 客户端使用 Core Location 计算震中距，再依据预计烈度决定是否强提醒。
4. 收到包含震源时刻与位置的低延迟首报后，计算 P/S 波预计到达时间；每次修订都更新倒计时。
5. 建立分级策略：远距离信息通知、本地有感警报、预计破坏性警报；避免只用震级阈值。
6. 若做非越狱正式 App，需要申请 Apple Critical Alerts 特殊 entitlement；未获批前不能承诺突破静音/勿扰。
7. 增加“演练”与“真实警报”强区分、辅助功能语音、地图、最近一次成功同步、数据源延迟和离线故障提示。

## 验证情况

- 全部 plist 已通过 Python `plistlib` 解析。
- Objective-C/Logos 文件的花括号及 `@interface`/`@end` 数量已做结构检查。
- USGS feed、USGS FDSN query、EMSC FDSN GeoJSON 在审查时均返回 HTTP 200 JSON。
- 当前 iSH 环境没有 `/var/mobile/theos` 及 iOS SDK，因此**未在本机完成最终 Theos 编译和真机运行测试**。压缩包内原有 deb 是旧版本产物，不代表本次修改已编译。

## 构建与测试建议

在安装好 Theos、iOS SDK 和对应注入框架的环境中：

```sh
make clean package FINALPACKAGE=1
```

至少执行以下真机用例：连续两次测试警报、关闭后再次报警、声音/振动四种组合、暂停开关、重启首次基线、锁屏/解锁/横屏、SpringBoard 重启、断网与主备切换、过期事件与异常时间事件。
